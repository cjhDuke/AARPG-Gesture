# PSI HAND v1.1.0

PSI HAND 是一款支持摄像头手势与键盘操作的 2D 像素生存游戏。穿过地牢和草地，在三选一强化中搭配技能，用挥剑和念力回旋镖迎战巫师 Boss。

## 版本亮点

- **本地存档与云同步**。支持多个手动存档，并在每波和 Boss 战开场保存最新的自动存档。读取自动存档会从该波开场重打。登录后可跨设备同步账号存档，也可将游客存档复制到账号。离线更改会先保存到本机，恢复联网后继续同步。
- **线上排行榜**。联网游客可浏览公开榜单。登录后，正常新局在第一波开始前取得线上资格即可参与排名。榜单优先比较九个里程碑中的完成进度，进度相同时比较到达最后一个已完成里程碑的有效用时。读档续玩不参与线上排名。
- **个人纪录**。登录后，同一账号的个人最高击杀数（**BEST KILLS**）可跨设备同步。

## Windows 安装与开局

1. 将 Windows 版 ZIP **完整解压**到同一文件夹，保留 `AARPG-Gesture.exe` 旁的配套文件及其目录结构。
2. 运行 `AARPG-Gesture.exe`，在主菜单选择 **START**。键盘默认可玩，无需摄像头或 Python。用 **WASD** 或方向键移动，按住 **L** 配合移动键引导回旋镖，松开 **L** 收回。
3. 账号为可选功能。用 **X** 或 **Esc** 关闭登录提示即可游客开局。云同步与线上成绩提交需要登录及网络连接。

如需使用摄像头手势，建议安装 Python 3.12，确认终端中的 `python` 可用，再在解压目录中运行以下命令安装 OpenCV 和 NumPy。

```powershell
python -m pip install -r gesture/requirements.txt
```

安装后重启游戏。显示 **KEEP HAND OUT** 时将手移出操作框，看到 **READY - HAND IN** 后伸手。张开手掌引导角色移动，握拳引导回旋镖，张开手掌收回。需要重新采集背景时按 **F3**。
