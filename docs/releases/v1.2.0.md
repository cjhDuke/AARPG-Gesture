# PSI HAND v1.2.0

## Windows 游戏内更新

- 第一次请下载并运行 `AARPG-Gesture-win-x64-Setup.exe`。安装后从桌面或开始菜单打开 **PSI HAND**。
- 后续版本可直接在主菜单选择 **UPDATE & START**，游戏会优先下载差分，安装完自动打开新版。选择 **LATER** 可继续玩当前版本。
- 同一 Windows 用户的存档、账号和游戏设置继续沿用。旧版操作框位置可在 **SETTINGS → AUDIO → IMPORT GESTURE SETTINGS** 选择旧 ZIP 解压目录中的 `gesture/state.json` 导入。
- 安装版更新会清理已废弃的程序文件，保留用户目录里的手势配置、录像和截图。旧 ZIP 和解压目录可在确认备份后自行清理。
